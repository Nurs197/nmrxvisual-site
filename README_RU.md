# NMRXVisual — комплект для размещения

Это автономный статический сайт. Для работы ему нужен только стандартный хостинг с поддержкой HTML, CSS и JavaScript. Серверная база данных и сборка проекта не требуются.

## Состав

- `index.html` — главная страница;
- `404.html` — страница ошибки;
- `assets/css/styles.css` — стили;
- `assets/js/main.js` — мобильное меню, проекты и форма;
- `assets/images/` — изображения и обложка для социальных сетей;
- `assets/fonts/` — локальные шрифты;
- `assets/icons/` — favicon;
- `robots.txt`, `sitemap.xml`, `site.webmanifest` — служебные файлы сайта;
- `hosting-examples/` — примеры переадресации для Apache и Nginx.

## Что заменить после выбора домена

Найдите `https://company.ru` в файлах:

- `index.html`;
- `robots.txt`;
- `sitemap.xml`;
- примерах конфигурации хостинга.

Замените этот адрес на подтверждённый основной домен, например `https://example.ru`.

## Быстрое размещение

1. Купите домен и хостинг самостоятельно либо пригласите исполнителя в аккаунт с ограниченными правами.
2. Загрузите содержимое этой папки в корневую папку сайта: обычно это `public_html`, `www` или `htdocs`.
3. В панели регистратора направьте домен на хостинг по DNS-записям, которые выдаст хостинг.
4. Включите бесплатный сертификат HTTPS в панели хостинга.
5. Выберите одну основную версию домена: с `www` или без `www`. Рекомендуемый вариант — без `www`.
6. Настройте постоянную переадресацию второй версии на основную. Примеры находятся в `hosting-examples/`.
7. После обновления DNS проверьте главную страницу, меню, проекты, WhatsApp, почту, форму, 404-страницу и отображение на телефоне.

## Безопасный доступ

Не отправляйте постоянные пароли в переписке. Используйте один из вариантов:

1. приглашение исполнителя отдельным пользователем с ограниченными правами;
2. временный пароль, который будет сменён сразу после запуска;
3. самостоятельное изменение DNS по подготовленной пошаговой инструкции.

## Данные, необходимые для подключения

1. Подтверждённое доменное имя.
2. Название регистратора домена и хостинг-провайдера.
3. Выбранный основной адрес: с `www` или без `www`.
4. Доступ к управлению DNS одним из безопасных способов выше либо готовность самостоятельно внести выданные записи.
5. Доступ к панели хостинга отдельным пользователем или временный доступ.
6. Данные для загрузки, если панель их требует: сервер, порт, протокол SFTP/FTP, имя временного пользователя и корневая папка сайта. Предпочтителен SFTP.
7. Возможность включить HTTPS в панели либо подтверждение, что сертификат выпускается автоматически.
8. Подтверждение, что заявки должны продолжать поступать в WhatsApp `+7 995 647-88-91`, а почта остаётся `levigarant26@gmail.com`.
9. Юридические тексты, если они обязательны для бизнеса: политика конфиденциальности, реквизиты владельца сайта и согласие на обработку данных.
10. Явное подтверждение на публикацию после финальной проверки.

Физический адрес на сайте не размещён. Если он понадобится, его следует предоставить отдельно перед публикацией.
