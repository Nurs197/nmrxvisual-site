## Обновление существующего репозитория

1. Распакуйте архив.
2. Загрузите содержимое папки `RezervTech_GitHub_Pages` в корень репозитория `nmrxvisual-site`.
3. Замените старые файлы новыми, не удаляя сам репозиторий.
4. В GitHub откройте `Settings → Pages`.
5. Оставьте публикацию из ветки `main` и папки `/ (root)`.
6. Дождитесь завершения публикации и откройте адрес сайта.

Создавать GitHub Pages заново и менять адрес репозитория не нужно.
