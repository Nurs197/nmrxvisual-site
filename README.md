# GOLD DISTRICT — Portfolio Demo

Адаптивный демонстрационный интернет-магазин игровых пакетов Gold, созданный на HTML, CSS и JavaScript без сборщика и сторонних JS-библиотек.

## Возможности
- Адаптивная навигация и мобильная версия.
- Каталог демонстрационных пакетов.
- Корзина с изменением количества и автоматическим подсчётом суммы.
- Форма заявки с проверкой обязательных полей.
- Подготовка текста заявки через Telegram Share URL.
- FAQ, блок контактов и дисклеймер о демонстрационном характере проекта.

## Запуск
Откройте `gold_portfolio.html` в браузере. Для GitHub Pages переименуйте файл в `index.html` и загрузите его в корень репозитория.

## Важно
Это портфолио-концепт, а не действующий магазин. Оплата, серверная обработка заказов, выдача товара и подтверждение платежей не реализованы. Все цены и игровые пакеты демонстрационные. Для реального коммерческого запуска потребуется backend, безопасная обработка персональных данных, интеграция платёжного провайдера и проверка прав на используемые обозначения.
